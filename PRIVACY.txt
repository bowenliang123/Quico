Quico - QR Code Generator Extension
Privacy Policy

Last Updated: 2026-09-01

This extension does not collect any personal data.

1. Data Collection
1.1 This extension does not collect, record, or upload any personal data, including but not limited to: name, email address, physical address, browsing history, or location information.
1.2 This extension contains no analytics, tracking, or advertising code, and does not send your data to any third-party server.

2. Local Data Storage
2.1 Data generated while using this extension, such as QR code content, saved QR codes, and recent generation history, is stored only locally in your browser (via chrome.storage) and is used solely to provide the extension's features.
2.2 This local data is entirely under your control. You can view or clear it at any time in the extension settings, and it will be removed by the browser when the extension is uninstalled.

3. Permissions
The permissions requested by this extension are used only to implement its core features:
- tabs: Read the URL and title of the current tab to generate QR codes.
- storage: Save your settings, saved QR codes, and recent history locally.
- bookmarks: Read bookmarks only when you explicitly choose to, to generate QR codes from them.
- contextMenus: Provide quick actions in the right-click context menu.

4. Miscellaneous
4.1 This extension does not communicate with any external server, so there is no risk of data leakage.
4.2 If you have any questions about this privacy policy, please contact us by opening an issue on the project's GitHub page.
